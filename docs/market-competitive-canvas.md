## 1. Рынок (кратко)

Розничные инвестиции в РФ стали массовыми. Молодёжь 18–26 **знает** акции, облигации, вклад и риск потери, но часто **не делает первый взнос**: нет практики, доход нестабильный, страх ошибки.

Типичный путь на рынке:

```
баннер «Инвестиции» → открытие счёта → витрина бумаг → опционально обучение
```

Слабое место рынка: персонализация и объяснение риска **до** покупки.  
Белое пятно для Альфы: первый шаг из повседневного сценария банка (кэшбэк / остаток / цель) + «почему именно это» без обещания доходности.

### Тренды, которые влияют на кейс

| Тренд | Что значит для Альфы |
|--------|----------------------|
| Дешёвые продукты (ETF / БПИФ / фонды ДР) | Первый шаг — conservative (LQDT и аналоги), не витрина акций |
| AI в инвестициях | Объяснение и чат — да; выбор бумаги моделью — нет |
| Конкуренция за CX и дистрибуцию | Фича внутри банка сильнее отдельного «ещё одного брокера» |
| Удержание youth vs Т-Банк | Ценность не только fee с 700 ₽, а primary-банк + счёт |

**KPI кейса:** +10% конверсии открытия инвестсчёта за год у когорты 18–26.

## 2. Карта игроков

Сравниваем не «кто лучше брокер вообще», а **кто закрывает путь новичка 18–26 до первого осознанного взноса**.

| Игрок | Кто это | Сильная сторона | Слабость для нашего кейса |
|--------|---------|-----------------|---------------------------|
| **Т-Инвестиции** | Бенчмарк UX и масштаба розницы | Удобное приложение, витрина, соц/обучающий контент, привычка «всё в одном банке» | После счёта быстро уводит в витрину; мало «зачем именно этот инструмент из кэшбэка» |
| **СберИнвестиции** | Экосистема Сбера | Простота, ПИФы, бесшовный кошелёк | Консервативный вход есть, но сценарий часто «банковский продукт», не персональный «первый шаг + почему» |
| **ВТБ Мои Инвестиции** | Крупный банк-брокер | IPO, ОФЗ, гибкие заявки | Сильнее для уже торгующих / охотников за размещениями |
| **БКС Мир инвестиций** | Независимый брокер | Скринер, аналитика, идеи | Ориентация на активного инвестора, не на страх первого взноса |
| **Финам (FinamTrade)** | Продвинутый терминал | Теханализ, уровни, тестер стратегий | Далеко от ЦА «знаю, но боюсь» |
| **Альфа-Инвестиции (как есть)** | Наш контур | PRO, API, Альфа-индекс, робот-советник, бренд банка | Мощный продукт для тех, кто уже внутри; вход новичка всё ещё ближе к «открой → витрина» |

## 3. Исследование конкурентов

### 3.1. Т-Инвестиции

**Позиция:** де-факто эталон мобильного брокерского UX в РФ; сильная связка банк + брокер.

**Что делают хорошо**
- низкий порог открытия счёта;
- понятный каталог и карточки бумаг;
- обучение и контент рядом с торговлей;
- привычка пользователя жить в одном приложении.

**Типичный путь новичка**
1. Баннер / раздел «Инвестиции»
2. Открытие счёта
3. Витрина / идеи / поиск тикера
4. Покупка (часто без глубокого «почему именно это под мою цель»)

**Чем опасны для Альфы**
- оттягивают молодёжь как **primary-банк**;
- задают ожидание «инвестиции = удобная витрина», а не «безопасный первый шаг».

**Чем не закрывают нашу нишу**
- слабый сценарий «свободные ₽ после кэшбэка → один conservative продукт + объяснение»;
- ИИ/помощник, если есть, не заменяет **правила выше модели** и учебный first step.

---

### 3.2. СберИнвестиции

**Позиция:** максимальная простота и доверие экосистемы; упор на пассив и ПИФы.

**Сильно:** вход «для ленивых», регулярные пополнения, связка с картой.  
**Слабо для кейса:** мало акцента на GenAI-объяснение выбора и на цель новичка (подушка / гаджет / поездка) до покупки.

**Вывод:** ближе всех к conservative first step по продукту, но не по персонализированному онбордингу «почему».

---

### 3.3. ВТБ Мои Инвестиции

**Позиция:** широкий банк-брокер; сила в размещениях, ОФЗ, заявках.

**Сильно:** календарь IPO, гибкие поручения, «индекс» поведения клиентов.  
**Слабо для кейса:** сценарий заточен под уже активного/интересующегося рынком, не под страх первого взноса 100–700 ₽.

---

### 3.4. БКС Мир инвестиций

**Позиция:** идеи, скринер, аналитика для активного инвестора.

**Сильно:** маркет-сканер, покупка с карт разных банков, внебиржа.  
**Слабо для кейса:** усиливает «охоту за идеями», а не снимает барьер «боюсь ошибиться раз и навсегда».

---

### 3.5. Финам

**Позиция:** терминал и теханализ.

**Сильно:** индикаторы, уровни, тестер стратегий.  
**Слабо для кейса:** прямо противоположный сегмент нашей ЦА.

---

### 3.6. Альфа-Инвестиции (текущий продукт банка)

**Позиция:** технологичный брокер Альфа-Банка для новичков **и** продвинутых.

**Уже есть (ориентиры рынка / открытые материалы)**
- PRO-терминал и API;
- «Альфа-индекс» настроений;
- робот-советник / автоподбор под риск;
- аналитика и подсказки по бумагам.

**Разрыв, который закрывает «Альфа-будущее»**
- робот и терминал помогают **управлять** портфелем тем, кто уже зашёл;
- кейс закрывает этап **до** и **в момент** первого взноса: цель → квиз → LQDT + альтернативы → «почему» → от 100 ₽;
- ИИ в кейсе **не** заменяет робота-советника: правила выбирают продукт, LLM пишет объяснение.

Иначе говоря: мы не конкурируем с PRO Альфы и не копируем Т на 150 экранов. Мы добавляем **вход для 18–26** в уже существующий контур Альфа-Инвестиций.

## 5. Типичный путь vs наш путь

| | Конкуренты (типично) | Альфа-будущее |
|--|----------------------|---------------|
| Точка входа | Баннер «Инвестиции» | Виджет: кэшбэк / остаток / цель |
| После входа | Витрина бумаг | Цель → 3 вопроса → карточка продукта |
| Первый продукт | Часто акции / идеи | LQDT (+ SBGB / FXRU) |
| Роль ИИ | Чат / идеи / робот | Только «почему», не выбор тикера |
| Успех | Счёт + любая сделка | Осознанный взнос от 100 ₽ |

```
Конкуренты:  Интерес → Счёт → Витрина → Сделка(?)
Мы:          Контекст банка → Цель → Квиз → Объяснение → Conservative взнос → Привычка
```

## 6. Наша ниша (вывод канваса)

**Занятое поле:** каталог, терминал, аналитика, роботы, IPO, теханализ — у Т, Сбера, ВТБ, БКС, Финама и у текущих Альфа-Инвестиций.

**Свободная ниша, которую занимает кейс:**

> Первый осознанный взнос из повседневного банка для 18–26:  
> знания есть → практики нет → маленький conservative шаг → понятное «почему» → без обещания дохода.  
> Правила выше ИИ. Фича Альфа-Инвестиций, не новый брокер.

**Позиционирование одной фразой**

Альфа-Инвестиции помогают не только торговать, но и **начать** — безопасно, из кэшбэка и цели, с объяснением, а не с витриной акций.

## 7. Что перенимаем / чего не копируем

| Перенимаем (как ориентир UX) | Не копируем |
|------------------------------|-------------|
| Простоту входа Т и Сбера | 150–200 экранов полного брокера в MVP |
| Экосистемность банка | Обещание доходности и «успей купить» |
| Идею обучения рядом со сделкой | Робот, который сам назначает рисковый актив |
| Силу бренда Альфа-Инвестиций | Отдельное приложение / отдельный стартап |
