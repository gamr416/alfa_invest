# Альфа-Инвестиции — подробная документация MVP

Дата фиксации: 17 августа 2026.  
Кейс: персонализация первого инвестиционного шага для молодой аудитории (Альфа-будущее).  
Реализация: отдельный mobile-first веб, оболочка «как банковское приложение», не встройка в прод Альфа-Банка.

---

## 1. Зачем это сделали

Розничные инвестиции стали массовыми, но когорта 18–26 **знает инструменты и боится практики**. Нестабильный доход, нет навыка первого взноса.

**Бизнес-цель кейса:** +10% конверсии открытия инвестсчёта за год; рост вероятности первого инвестиционного действия.

**Цель этого MVP:** показать, что инвестиции можно начать просто и без страха: туториал маскота, первый взнос от 100 ₽ в консервативный инструмент, дальше учебный брокер (paper) с каталогом, сделками, пульсом, учёбой и ИИ-агентом.

Ограничения, которые держали в продукте:

- ЦА GTM: **18–26**, знания есть, практики нет (ADR-0002).
- Не обещать доходность.
- Не marжа, не крипта, не отдельное приложение.
- ИИ не выбирает бумагу: правила и UI выбирают продукт, модель объясняет и чатит.
- Светлая тема, акцент `#EF3124`, чёрный и белый. Без liquid glass и без тёмной темы.

## 2. Решения с гриля (зафиксировано)

| Вопрос | Решение |
|--------|---------|
| Формат | Отдельный mobile-first веб (Vite), рамка телефона ~390px |
| Каталог | Полный брокер-демо на стабах (акции есть). Первый заход — консерватив LQDT |
| Экраны | Не 150–200 как Т-Инвестиции, а 6 хабов + дочерние |
| ИИ | Реальный Ollama `bonsai-27b:latest`; если нет сервера — fallback-текст |
| Сессия | Сразу клиент 18–26, без логина |
| API банка и рынка | Заглушки в `server/stubs/` |

Срезы 18–21 / 22–26 — формулировки, не отдельные системы. 14–17 — не GTM.

## 3. Стек и как запустить

```
web/      Vite + React + TypeScript + React Router
server/   FastAPI + uvicorn, портфель в памяти процесса
.venv/    Python-зависимости (не в git)
```

Терминал 1 — API:

```bash
cd alfa_invest
source .venv/bin/activate
cd server && uvicorn main:app --host 127.0.0.1 --port 8000
```

Терминал 2 — UI:

```bash
cd alfa_invest/web
npm run dev
```

Vite проксирует `/api` на `http://127.0.0.1:8000` (`web/vite.config.ts`).

Открыть: http://127.0.0.1:5173

Ollama (живой агент):

```bash
ollama serve          # если не запущен
ollama list           # должна быть bonsai-27b:latest
```

Выключить модель только для приложения (демо fallback), не трогая демон:

```bash
OLLAMA_URL=http://127.0.0.1:1 uvicorn main:app --host 127.0.0.1 --port 8000
```

Профиль тогда показывает «офлайн», чат отвечает шаблоном с именем клиента.

## 5. Пользовательский путь

### Онбординг (`/onboarding`)

Показывается, пока нет `localStorage.alfa-onboarded` и серверного флага `onboarded`.

1. Привет (маскот hello), кэшбэк с карты.
2. Цель: подушка / гаджет / поездка (маскот type).
3. Три вопроса: горизонт, приоритет, сумма.
4. Карточка LQDT + альтернативы SBGB / FXRU; текст «почему» от Ollama (или fallback).
5. Сумма взноса (type), покупка LQDT (buy), paper-ордер.

Пропуск тоже ставит onboarded и пускает в приложение.

### После онбординга — нижние вкладки

1. **Портфель** `/` — сумма, кэш / бумаги / позиции, баннер первого шага, плитки, активы, «движение рынка», блок «сегодня».
2. **Каталог** `/catalog` — поиск, чипы подборок, список бумаг.
3. **Пульс** `/pulse` — лента постов с фильтром тегов.
4. **Учёба** `/learn` — микроуроки, прогресс в `localStorage`.
5. **Профиль** `/profile` — карта/кэшбэк/копилка, статус Ollama, тариф агента, документы.

### Отдельные окна (без таббара, стрелка в шапке)

- `/instrument/:ticker` — карточка: график-свечи, стакан, показатели, Купить / Продать.
- `/buy/:ticker` — заявка; `?side=sell` сразу продажа.
- `/operations` — лента сделок.
- `/analytics` — PnL, покупки/продажи/комиссии, круг состава, бары по бумагам.
- `/agent` — мессенджер с аватаром.
- `/pulse/:id`, `/learn/:id`, `/learn/league`.

Назад — стрелка слева в красной шапке «АЛЬФА ИНВЕСТИЦИИ», не текстовая кнопка.

Пустые списки: плачущий маскот и «Ничего нет, но всё ещё впереди».

## 8. API

База: `http://127.0.0.1:8000`. CORS открыт для демо.

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/health` | API ok + статус Ollama |
| GET | `/api/me` | Профиль (Аня, female, 21, остаток, кэшбэк, копилка) |
| GET | `/api/portfolio` | Кэш, позиции, onboarded, goal |
| POST | `/api/onboard` | `{ goal }` — флаг онбординга |
| GET | `/api/operations` | Лента (сделки + комиссии) |
| GET | `/api/instruments` | `?q=&kind=all\|stock\|etf\|conservative` |
| GET | `/api/instruments/{ticker}` | Карточка + sparkline + **candles** + book + metrics |
| POST | `/api/orders` | `{ ticker, side: buy\|sell, qty, order_type }` paper |
| POST | `/api/agent/chat` | `{ messages, context? }` — Ollama или fallback |
| GET | `/api/pulse` | Посты |
| GET | `/api/academy` | Уроки |
| GET | `/api/referral` | Share-only код, путь `/onboarding?ref=`, счётчик. Заголовок `X-Demo-User` |
| POST | `/api/referral/claim` | `{ code }` — атрибуция, без награды; свой код → 400 |
| GET | `/api/league` | Лига практики: Аня + 3 сида, очки не из PnL |
| POST | `/api/academy/progress` | `{ done, streak }` — синк уроков для лиги |

Демо-юзер: uuid в `localStorage` (`alfa-demo-user`), заголовок `X-Demo-User`. Без заголовка API считает Аню.

Портфель **в RAM процесса**: рестарт uvicorn обнуляет сделки. Стартовый кэш 10 000 ₽.

Комиссия paper: `max(0.05% от суммы, 1 ₽)`.

### Свечи

`market.candles()` — OHLC на 24 дня, последняя close ≈ текущая цена. Фронт режет 7/14/24 дня.

### Стакан

8 уровней bid/ask вокруг цены. В UI: цена ₽ и лоты, подписи что это чужие заявки «сейчас».

## 9. ИИ-агент

Файл: `server/ollama_client.py`.

- Модель: `bonsai-27b:latest` (в окружении была Q1_0, ~3.8 GB).
- `think: false` — иначе у модели пустой `content` и только thinking.
- `num_predict`: 420. Таймаут чтения 240 с.
- В system: когорта 18–26, знания есть / практики нет, без обещания доходности, не выбирать бумагу, без юрхвоста.
- Блок клиента из `alfa.get_me()`: имя, возраст, **род**. Для Ани — женский («готова / поняла»).

Fallback (нет соединения / ошибка HTTP):

> Аня, я сейчас без нейросети — сервер ассистента не отвечает. Можешь без меня: учёба… LQDT от 100 ₽…

Чат UI: фон как мессенджер, пузыри, поле снизу, аватар у реплик бота и «печатает…».

Баг, который чинили: параметр `client` профиля нельзя называть так же, как `httpx.AsyncClient` — в except используем профиль, HTTP-клиент назван `http`.

## 11. Метрики кейса (ещё не в коде)

Северная звезда: доля 18–26 с первым осознанным взносом за 90 дней после показа.

Воронка: показ → старт → обучение → риск → выбор → счёт → взнос → повтор за 30 дней.

A/B: виджет vs путь «Инвестиции» — в этом репо не реализован, это демо-оболочка.

## 13. Навигация (граф)

Онбординг живёт вне `PhoneShell`. После гейта всё внутри рамки телефона.

```
/onboarding
     │  localStorage alfa-onboarded=1 + POST /api/onboard
     ▼
/  (портфель) ──┬── /operations
                ├── /analytics
                └── табы: /catalog /pulse /learn /profile
                              │
/catalog ── /instrument/:ticker ── /buy/:ticker[?side=sell]
/pulse   ── /pulse/:id
/learn   ── /learn/:id
         └── /learn/league
/profile ── /agent
```

`parentOf()` в `PhoneShell.tsx` задаёт, куда ведёт стрелка:

| Текущий путь | Назад |
|--------------|--------|
| `/instrument/*`, `/buy/*` | `/catalog` |
| `/agent` | `/profile` |
| `/operations`, `/analytics` | `/` |
| `/pulse/:id` | `/pulse` |
| `/learn/:id`, `/learn/league`, `/learn/compound` | `/learn` |
| хабы с табами | стрелки нет |

Таббар скрыт, если путь начинается с `/buy`, `/instrument`, `/agent`, `/operations`, `/analytics` или это деталь пульса/урока.

Гейт: если нет `localStorage.alfa-onboarded === '1'` и `portfolio.onboarded === false`, любой путь кроме `/onboarding` редиректит на онбординг. Если API недоступен, достаточно локального флага.

## 15. Paper-ордер (поведение)

Реализация: `server/stubs/portfolio.py`.

- Старт: `cash = 10000`, позиции пустые, `onboarded = false`.
- Цена исполнения = текущая `inst["price"]` (рыночная; `limit_price` в модели есть, демо бьёт по рынку).
- Комиссия: `max(notional * 0.0005, 1.0)` ₽, списывается с кэша отдельно и пишется в `ops` как комиссия.
- Buy: не хватает денег (qty × price + fee) → `400`.
- Sell: нет позиции / qty больше, чем есть → `400`.
- Средняя цена позиции пересчитывается при докупке.
- Снимок: `total = cash + Σ qty×price`, `day_pnl` = сумма нереализованного PnL (не «за день», а vs avg).

Рестарт uvicorn = новый виртуальный счёт. Флаг онбординга на сервере тоже сбрасывается; клиент может остаться «уже внутри» из-за localStorage.

## 16. Переменные окружения API

| Переменная | По умолчанию | Зачем |
|------------|--------------|--------|
| `OLLAMA_URL` | `http://127.0.0.1:11434` | хост Ollama; для форс-fallback ставят несуществующий порт |
| `OLLAMA_MODEL` | `bonsai-27b:latest` | имя модели; с фронта не выбирается |

Запрос чата: `POST /api/agent/chat` `{ "messages": [{ "role", "content" }], "context"? }`.  
Успех: `{ "ok": true, "reply", "model" }`. Fallback: `{ "ok": false, "reply", "error", "model", "fallback": true }`.

Опциональный `context` вставляется отдельным user-сообщением `[Контекст продукта]`, чтобы объяснить карточку LQDT на шаге онбординга, не отдавая модели выбор инструмента.
