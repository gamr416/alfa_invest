# Документация проекта: персонализация инвестиций для молодой аудитории

Кейс «Альфа-будущее». Решение встраивается в мобильное приложение Альфа-Банка.

## 1. Контекст и проблема

За 10 лет розничные инвестиции стали массовыми. Экономически активная молодёжь 18–26 знает про акции, облигации и вклад, понимает инфляцию и риск потери, но **не делает первый взнос**: нет практики, доход нестабильный, страх ошибки.

**Бизнес-задача:** довести молодых клиентов от интереса до первого осознанного и безопасного действия (счёт, обучение, подходящий инструмент).

**Цели кейса:** +10% конверсии открытия инвестиционного счёта за год; рост вероятности первого инвестиционного действия.

**Ограничения:** согласие родителя и возрастной фильтр для <18; нельзя подталкивать несовершеннолетних к риску; нельзя обещать доходность; не отдельный стартап, а фича банка.

## 2. Целевая аудитория

Рабочая когорта (**ADR-0002**): **18–26**, студенты / выпускники / начинающие специалисты, без счёта или пустой счёт. Знания базовые, практики нет. 14–17 не расширяют Age Gate MVP.

Почему не 14–17:
- нет родительского контура;
- есть Bank Context (остаток, копилка, кэшбэк);
- интерес есть, доход дырявый, привычки нет.

Срезы (copy, не модули):
- 18–21: учёба, стипендия/подработка, страх «маленькой суммы»;
- 22–26: выпуск / джун, кэшбэк и копилка, цель «подушка / не съела инфляция / поездка».

## 3. Боли, барьеры, мотивации

| Боли | Барьеры | Мотивации |
|------|---------|-----------|
| Знаю про акции — не знаю, с чего начать | Страх потери при первом взносе | Защита от инфляции мелкой суммой |
| Доход скачет, «это не для меня» | Нет практики, только теория | Привычный мобильный банк |
| Боюсь ошибиться раз и навсегда | Витрина акций вместо первого шага | Понятный «зачем» без обещания заработка |

Первый шаг, который считаем целевым: **осознанный взнос от 100 ₽ в консервативный инструмент** (фонд денежного рынка или облигационный БПИФ) после короткого обучения и объяснения выбора.

## 4. Как устроен вход (ориентир по рынку)

Типичный путь конкурентов: баннер «инвестиции» → открытие счёта → витрина бумаг → опционально обучение. Слабое место: персонализация и объяснение риска до покупки. Белое пятно для нас: **первый шаг из повседневного сценария банка + «почему именно это» без обещания доходности.**

## 5. Продуктовые гипотезы (GenAI)

1. **Первый шаг на сдачу.** Ассистент предлагает сумму из кэшбэка/остатка в фонд денежного рынка и объясняет, почему сумма безопасна для бюджета.  
   Проблема: мало денег. Эффект: первый взнос. Сложность: средняя.

2. **Почему именно это.** Цель (подушка / телефон / поездка) → 3 вопроса риска → один инструмент и две альтернативы простым языком.  
   Проблема: не понимают выбор и риск. Эффект: осознанность и меньше отказов. Сложность: средне-высокая.

3. **Тренер привычки на 4 недели.** Микроуроки и напоминание регулярного взноса, без давления на риск.  
   Проблема: нет привычки. Эффект: повторный взнос. Сложность: ниже средней.

Проверка: кликабельный прототип + диалог с ИИ, опрос 15–20 человек когорты. Сигналы: клик по точке входа, доходимость обучения, открытие счёта, первый взнос.

Приоритет MVP (гипотеза 2 + кусок 1): цель → риск-квиз → объяснение → демо-портфель → взнос от 100 ₽.

Must: возраст, дисклеймеры, без обещания доходности, объяснимость.  
Should: сумма из остатка.  
Could: родительский контур.  
Won’t: акции, крипта, маржа, отдельное приложение.

## 6. Персонализация

Гибрид, не чёрный ящик:
- **правила** выбирают допустимый продукт (возраст, риск, горизонт, квалификация, запреты ЦБ);
- **контекст клиента** (остаток, копилка, кэшбэк, регулярный доход) влияет на сумму и формулировку цели;
- **генеративный ИИ** пишет только текст «почему выбрано это, а не альтернативы» по уже отобранному продукту.

ИИ не назначает рисковый актив и не обещает доходность. Перед показом — фильтр формулировок.

## 7. MVP: сценарий

Точка входа: виджет в приложении («свободные 700 ₽ после кэшбэка» / «цель: подушка»).

Экраны (черновик): цель → 3 вопроса → 60–90 сек про риск → карточка продукта + 2 альтернативы + «почему» → дисклеймер → открытие/активация счёта → первый взнос / регулярный платёж.

Поддержка: подсказки ассистента, прогресс обучения, родительский стоп-кран для <18.

## 8. Риски и снятие

- Продукт: манипуляция новичком → только консервативный первый шаг, сравнение альтернатив.
- Регуляторика: обещание доходности, <18 → шаблоны, возрастной гейт, согласие родителя.
- Этика: давление «успей купить» → спокойный тон, обучение до сделки.
- Технологии ИИ: галлюцинации → правила выше модели, аудит ответа.
- Данные: лишняя персоналка → агрегаты, не сырая лента трат.
- Мошенничество: фишинговые «рекомендации» → только внутри приложения банка.

## 9. Промо (черновик)

Когорта 18–26 в приложении. Сообщение: «Знаешь, что такое вклад и риск. Первый шаг — маленькая сумма, без обещания заработка».

## 10. Метрики

Северная звезда: доля 18–26 с первым осознанным взносом за 90 дней после показа фичи.

Воронка: показ виджета → старт → обучение → риск-профиль → выбор → счёт → первый взнос → повтор за 30 дней.

Цель кейса +10% открытия счёта: A/B виджета против текущего пути «Инвестиции».
