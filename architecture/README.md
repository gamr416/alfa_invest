# Архитектура: Альфа-будущее

Фича / демо: mobile-first веб «Альфа · Инвестиции».

## ЦА (пока так)

**18–26**, экономически активные (студенты / выпускники / джуны). Знают акции, облигации, вклад и риск потери; боятся первого взноса из-за отсутствия практики и нестабильного дохода. Нет счёта или счёт пустой. ADR-0002.

План «как на много пользователей» (упражнение, Compose): [distributed.md](distributed.md).

Персональные данные граждан РФ не собирать и не хранить на зарубежном аналитическом/облачном SaaS (152-ФЗ ст. 18). Ollama и стабы — локально.
