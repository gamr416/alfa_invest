# Распределённая система (план, упражнение)

Не прод и не «лям RPS». Слои как у сервиса на много пользователей; крутится локально в Docker Compose.

Сейчас MVP: один FastAPI, портфель в RAM, рынок-стаб, один клиент без логина, Ollama сбоку.

## Решения

| Тема | Как |
|---|---|
| Сделки | Paper: учебные деньги, ордер исполняется сразу в API, без биржи и очереди |
| Юзер | В проде — SSO / аккаунт Альфа-Банка. Здесь — `user_id` «уже после логина», SSO не собираем |
| Правда | Один Postgres |
| Котировки | Redis: last / стакан / sparkline. Источник — тот же стаб, что `server/stubs/market.py` |
| Кто пишет Redis | API (старт или cache-miss). Отдельного ingest-воркера нет |
| Агент | Продуктово обязателен (помощник). В Compose — профиль, **без** `depends_on`. Ордер модель не ждёт. История чата на бэке не хранится |
| Пульс / академия | Таблицы **в том же** Postgres. Не Mongo, не второй Postgres |
| Compose | `web`, `api`, `postgres`, `redis`. `ollama` — `--profile gpu` |
| Не брать | Kafka, k8s, nginx, второй инстанс API, matching engine, лента MOEX |

Деньги и qty в Postgres: `numeric`, не `float`. Redis можно потерять и перегреть из стаба.

## Слои

```
браузер
  → web
  → api (stateless)
       → Postgres   юзер, кэш, позиции, ордера, операции, каталог бумаг, пульс, академия
       → Redis      горячие котировки
       → Ollama     чат (если жив; иначе fallback-текст как сейчас)
```

На «ляме» сверху был бы балансер и несколько api. В репо — один api.

## Postgres (SoT)

- пользователь (`user_id` с внешнего SSO)
- paper-счёт: кэш, onboarded, цель
- позиции
- ордера и операции
- справочник инструментов (тикер, имя, тип, лот) — «меню»
- `pulse_items`, `academy_lessons`

Каталог ≠ котировка. Меню редко меняется — Postgres. Табло часто — Redis.

## Redis (кэш рынка)

Ключи вида котировки по тикеру. Не портфель, не история свечей за годы.

Пропажа Redis = API снова кладёт стаб. Пропажа Postgres = потеря счёта — недопустимо.

Внешняя лента (MOEX/брокер) — позже: тот же контракт ключа, другой писатель.

## Агент

ИИ не выбирает бумагу (как в MVP). Объясняет и чатит.

Compose: сервис есть, api стартует без GPU. UI агента не прячем; нет модели — честный офлайн-текст.

Чат: фронт шлёт историю в `POST /api/agent/chat`. Таблица сообщений — когда понадобится другой девайс.

## Compose

Дефолт: `web` + `api` + `postgres` + `redis`.  
Профиль gpu: ещё `ollama`.

Volume только у Postgres. Redis — эфемерный.

## Путь от MVP

1. Postgres + `user_id`, убрать in-memory портфель.
2. Каталог и контент — сиды в PG.
3. Redis + запись котировок из стаба в API.
4. `docker-compose.yml`.
5. Профиль Ollama.
