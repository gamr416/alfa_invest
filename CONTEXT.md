# Domain glossary — Альфа-будущее

Рабочий продукт: фича персонализации первого инвестиционного шага внутри приложения Альфа-Банка.

## Locked for MVP

**Working Cohort** — экономически активная молодёжь РФ **18–26** (студенты, выпускники, начинающие специалисты) без инвестсчёта или с пустым счётом. Знают инструменты и риск на уровне «слышал»; не умеют сделать первый взнос. Срезы 18–21 / 22–26 — copy, не модули. ADR-0002.

**Minor Contour** — 14–17. Не Working Cohort. Не вход MVP.

## Concepts

**First Conscious Contribution** — осознанный взнос от 100 ₽ в консервативный инструмент. Снимает страх «я не умею», не учит азбуке рынка.

**Conservative Instrument** — фонд денежного рынка или облигационный БПИФ. Акции в каталоге — с бейджем риска, не первый шаг.

**Bank Context** — остаток, копилка, кэшбэк при нестабильном доходе. Не сырая лента трат.

**Goal** — подушка / гаджет / поездка / не съела инфляция.

**Risk Quiz** — учебные вопросы про горизонт, не тест ЦБ.

**Product Card** — один инструмент + две альтернативы + «почему», без обещания доходности.

**Eligibility Rules** — правила выше модели.

**Explanation Copy** — ИИ пишет только «почему это», не выбирает бумагу.

**Age Gate** — отказ младше 18. GTM и метрики: 18–26. Выше 26 — фича может быть, KPI кейса не на них.
